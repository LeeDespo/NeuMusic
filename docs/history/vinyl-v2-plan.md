## 1. 布局与几何（用户点名）

### 1.1 唱片居中 + 底座抬高
- **唱片必须水平居中**：现在盘心在舞台坐标 `DISC_CX = 0.50`、舞台宽 `1.225 D` —— 盘心确实是 0.50 但**舞台本身比盘宽**（右侧留给唱臂扫掠），若舞台在 `BoxWithConstraints` 里居中，盘就偏左了。v2 改为：**以唱片为对齐基准**，唱臂允许溢出舞台（`graphicsLayer` 不裁剪），或舞台宽度改为 `max(盘, 唱臂扫掠右缘)` 并让盘的圆心落在父级正中。
- **唱臂底座纵坐标抬高**（用户原话「不要贴得唱片太近，纵坐标更高些」）：
  - x：**与唱片这个圆的最右端点的 x 一致**（用户明确，就是 `盘心x + 盘半径`，即 `0.50 + 0.50 = 1.00 D`）。
  - y：比现在更高（现在 `PIVOT_DIST = 0.614 D @ −39°` → 支点在盘心右上）。v2 取 **底座圆心 y ≈ 盘心 y − 0.42 D**（约为盘缘上方 0.08 D），具体数值在实验室里对参考图校准后定死。
  - 副作用：支点到盘心距离变大 → `ARM_LEN` 与三个臂角（待机/外圈/交界）都要按新支点重解 —— **仍然用现有的 `armAngleForRadius()` 反解，不要手填角度**（上一轮的教训）。

### 1.2 舞台尺寸
- 舞台宽度需重算：底座 x = 1.00 D + 底座半径，右侧还需给底座的外阴影留 ~0.06 D。
- 舞台高度：盘顶到盘底 + 上下阴影留白；底座抬高后整体高度会更紧，注意报错别让底座被裁。

## 2. 唱片纹理：双层面板（修改方案 1）

- 分 `外层纹理区`（现有那圈疏密相间的弧线，**保留**）与 `内层纹理区`（靠近片心，**致密 + 更深的纹路**）。
- 允许简化：内层**可以直接用一个更深的色块**（用户明确「或干脆是一个色块，以减少工作量」）。
- 两区之间要有**视觉过渡**（现实黑胶的"过渡带"）：建议在交界处留一圈空带 + 一条稍强的弧线作为分隔。
- 现有 `VinylGeo.GROOVE_RADII` 是 17 个半径的浮点表（疏—密两段），v2 建议改成两组：`GROOVE_OUTER`（现有外圈那批）+ `GROOVE_INNER`（致密，步长更小、颜色更深）。
- **性能红线（上一轮实测）**：`sweepGradient` 会带来 ~12.6% 卡顿，**不要用**；内层用纯色块或普通圆弧 + 2° 端部重叠（这是上一轮已验证的做法，见实验室 README）。

**与唱头轨迹的关系（重要）**：内层纹理区的外缘 = §3 里唱头播放终点所在的「交界处」半径，两者必须用同一个常量，否则唱头会停在纹理之外。

## 3. 唱头运动与姿态（修改方案 2）

### 3.1 删掉的东西
- 唱针（红线/红点）**删除**。
- 唱头的落针下压（`stylusDown` 缩一缩）**删除**。
- 于是「唱头 + 唱臂」成为一个**刚体**，它唯一的动画是**绕底座转轴的圆弧转动**。

### 3.2 两段式圆弧轨迹（连续、无顿挫）
唱头针尖半径 `r` 沿一条弧线由外向内：

| 段 | 区间 | 性质 | 触发 |
|---|---|---|---|
| 段 1 · 起播 | 待机位 → 外圈起点 `R_OUT` | **连贯单段缓动**，不许出现「先快后停再动」的断点（用户明确投诉现在的顿挫） | 点播放后 |
| 段 2 · 播放 | `R_OUT` → 交界处 `R_IN` | **与播放进度严格线性绑定**：`r = R_OUT + (R_IN − R_OUT) × progress` | 播放中 |
| （暂停） | 抬回待机位 | 反向走段 1 | 暂停 |
| （结束） | 停在 `R_IN` | —— | 播完 |

- 角度仍由 `armAngleForRadius(r)` 反解，于是「半径线性变化」=「角度按余弦律变化」，天然是弧线而不是直线平移。
- **不要试图让唱头落在真实音轨上**（用户明确："不用求什么一定要落到胶片的音轨上"），只需要视觉上是从外到内扫过。
- `progress` 来源：`PlayerHost.position / duration`。现有的 500ms 轮询太粗（会一顿一顿），v2 需要在播放页拿到**更细的位置**（见 §5 的探针要求）。

### 3.3 姿态内折（Offset Angle）
- 现实唱机唱头相对唱臂轴线**向内折 15°~23°**。v2 取 **18°**（中间值，可调常量 `HEAD_OFFSET_DEG`）。
- 几何：唱臂是一根直线（从底座到连接点）；**唱头绕连接点再单独旋转 −18°**（屏幕系 y 向下，向盘心方向折），并**指向圆心**。
- 实现：唱头是一个独立的绘制/布局单元，位置 = 臂末端，旋转 = 臂角 + 内折角。**不要再把它画成臂的延长线**。

### 3.4 由此带来的状态机简化（重要取舍）
上一轮的 5/6/7/8 条（4240ms 提前量、3 秒静默窗口、换片 re-aim）**在新的"进度绑定弧线"下大部分不再需要**：

- 唱头位置直接跟着播放进度走 → **不再需要"提前量把整套动画塞进曲尾"**；
- 抬臂/回位仍是短过渡（`armLift` + `armReturn`），换片仍由 `PlayerHost` 的 `ENDED→advance` 送来新封面；
- **但「手动快速切歌的 3 秒静默窗口」需要确认是否还要**（用户上一轮明确要；本轮说"按歌曲时间和播放进度一直走圆弧移动轨迹就行"）。**方案默认保留**：切歌时先抬臂回位 + 转盘减速，静默 3 秒内不再切歌才继续换片 —— 若用户不要，把它作为可关的常量。
- **`discSwap` 的 re-aim（要求 8）**：仍建议修（`VinylTurntable.kt:356-357` 在进入时就取 `pendingCover`，把 620ms 窗口内到达的新切歌丢掉），改成进入时先 `drain()` 再取 —— 与实验室 `VinylMachine.kt:515-519` 一致。**这一条无论 v2 怎么简化都建议做**，它是纯 bug。

## 4. 唱臂三件套改 M3 风格（修改方案 3）

**风格总则（已写入 AGENTS.md，本轮首次落地）**：新拟物为主、**M3 为辅**；不好用新拟物表达的元素用 M3 点缀。

### 4.1 形状
| 件 | 形状 | 现有常量（改造对象） |
|---|---|---|
| 唱臂 | **胶囊形**（圆角极大的长条），或大圆角长条 | `ARM_W = 0.029 D`（太细、像铅笔芯） |
| 唱头 | **倒角矩形**（rounded rectangle），绕连接点内折 18° | `HEAD_L = 0.135 D` / `HEAD_W = 0.105 D` |
| 底座转轴 | **同心圆**（两三层同心圆 / 圆柱体观感） | `PIVOT_BASE_R = 0.10 D` |

**不描边，靠色块区分**（用户明确）。

### 4.2 色彩
- 放弃 `metalHi = #F8FAFC` / `metalLo = #2A2E33` 这套高对比黑白灰。
- 改用 **M3 角色色**：
  - 底座/转轴：`surfaceContainerHighest`（或 `surfaceVariant`）
  - 唱臂：`secondaryContainer`（或 `surfaceContainerHigh`）
  - 唱头：`secondary` / `primaryContainer`（要能看出是"另一个部件"）
- ⚠️ **前置改动**：`ShadeTheme`（`shade/Shade.kt`）目前只显式设了 `background/surface/onBackground/onSurface/primary` 五个角色，其余会落到 M3 基线紫。**必须先在这些角色里按 `ShadeColors` + 强调色补上** `surfaceContainerHighest` / `secondaryContainer` / `surfaceVariant` / `outlineVariant` 等，且要在深浅两套下都好看。这是本轮的**第一个改动**，否则后面全是紫的。

### 4.3 阴影（Elevation）
- 唱臂、唱头要**柔和且有深度**的投影，体现"悬浮"或"机械叠层"。
- 用 elevation 语汇：**大模糊 + 低透明 + 可用两层**（key 影短而实、ambient 影长而虚）。这**不是**新拟物的"一亮一暗两影"，不要混用。
- 现有 `shadeVec()`（`VinylTurntable.kt:427-435`，与 `Shade.kt` 的 `shadowVectors` 同算法）是**新拟物两影**——唱臂改 M3 后**不要再用它**，改用新的 M3 elevation 绘制（底盘/唱片仍用新拟物光影，两者要能并存）。

## 5. 播放页 LED 胶囊可视化（新要求）

### 5.1 位置与尺寸
- 位于**唱片与歌名之间**，**水平居中**，**长度 = 唱片直径**。
- 只在黑胶模式下出现（普通模式仍有原来的频谱环）。

### 5.2 形态
- **一排 LED 胶囊**（segmented LED bar）：等宽小胶囊横向排列，每根按电平点亮若干格，或每根胶囊整体亮度/高度随电平变化。
- 风格两选一（用户允许）：**新拟物风**（凹陷槽 + 胶囊填充）或 **M3**（胶囊用角色色 + elevation）。建议：**槽用新拟物凹陷**（与播放页其它控件一致）、**胶囊用 M3 色**（与本轮"M3 为辅"呼应）。
- 数据源：现成的 `VizHost.levels`（16 段）/ `PlayerHost.vizProcessor.levels`（PCM 回退），按现有的降采样映射铺开（播放栏与频谱环用的是 `VIZ_BARS = 40`，可沿用或按胶囊宽度调整）。
- 性能：电平流每次音频块都发射（~20-50ms），**订阅必须下沉到胶囊组件内部**（与 `CircularCoverViz` / `CoverDisc` 同款隔离做法，见性能审计批次）。

### 5.3 关于「网上方案」
本轮调研时 **WebSearch 不可用**，但不需要外部方案：LED 胶囊 = `Canvas` 画圆角矩形 + 电平驱动 + `BlurMaskFilter` 发光（应用已有原生模糊的绘制基元，见 `Shade.kt:150`）。如果实现时想要更"发光"的观感，可给点亮格加一层更亮的同色描边/小半径模糊。
